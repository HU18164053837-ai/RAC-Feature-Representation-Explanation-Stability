# Bounded workflows

The safe gate adapts existing saved-output verification. It does not repeat model inference. Original inverse/permutation/additivitychecks passed inv1.1and saved audits remain. Numericalmodulesretain scientific relativepaths for compatibility. Path_Mapping.csv records every copied file. Standalone wrappers are packaging additions. Historical paths used by model files are relative; installed environments are omitted. Codelicense/modelrelease rights require owner confirmation.

For optional plotting also install requirements_historical.txt because original numerical modules import their historical model classes. These are import dependencies, not permission to runHPO. The root gate deliberately needs only standardlibraryPython.
