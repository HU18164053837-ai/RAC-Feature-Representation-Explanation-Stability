# Human release checklist

- [ ] Confirm authors, affiliations, corresponding author and CITATION.cff.
- [ ] Confirm release rights; choose the actual code/model license.
- [ ] Retain data attribution and modification notice.
- [ ] Run scripts/verify_saved_results.py and inspect docs/GitHub_Release_QA.md.
- [ ] Review privacy scan and final file scope.
- [ ] Create/upload the repository yourself; no GitHub action has been performed.
- [ ] Insert actual GitHubURLonly after upload.
- [ ] Optionally create a versionedRelease and archive viaZenodoorinstitutionalrepository; insert only an issuedDOI.
- [ ] Confirm manuscript declarations, AI-use scope and availability statement.

The test set is consumed. Release preparation does not authorize model development.
